Bem-vindo ao repositório do **Rescue the Prisoner Game**! 

Este é um projeto nostálgico e muito divertido que desenvolvi no início da minha jornada como desenvolvedor. Trata-se de um jogo web interativo criado com o objetivo principal de treinar e aprofundar o manejo e a manipulação dinâmica de elementos do DOM na tela.

## 📖 Sobre o Projeto

O **Rescue the Prisoner** ("Resgate o Prisioneiro") desafia o jogador em uma mecânica simples, mas envolvente. O foco por trás da criação deste projeto não foi apenas a diversão, mas sim entender de forma prática como o JavaScript interage com a página web em tempo real: criando, movimentando, alterando propriedades e removendo elementos do DOM de acordo com as ações do usuário e a lógica do jogo.

Manter este repositório é uma ótima forma de olhar para trás e ver como os fundamentos de lógica e manipulação de elementos visuais foram construídos desde o início! 🚀

## ✨ Funcionalidades e Aprendizados

- 🕹️ **Manipulação de DOM em Tempo Real**: Atualização dinâmica de posições, estados e elementos na tela.
- 🎯 **Lógica de Jogo Interativa**: Eventos de clique e interações do usuário que afetam diretamente o andamento da partida.
- 🎨 **Estilização Dinâmica (CSS3)**: Uso de elementos visuais e posicionamentos para criar a atmosfera do jogo.
- ⏱️ **Feedback Visual**: Respostas instantâneas na interface de acordo com as ações tomadas pelo jogador.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando apenas as tecnologias essenciais da web, sem frameworks ou bibliotecas externas:

- **HTML5**: Estrutura dos elementos da interface e da área de jogo.
- **CSS3**: Estilização visual, layout e efeitos estéticos.
- **JavaScript (Vanilla)**: Lógica do jogo, controle de eventos e manipulação avançada do DOM.

## 🚀 Como executar o projeto localmente

Por ser um projeto puramente em HTML, CSS e JavaScript vanilla, executá-lo é extremamente simples:

1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com/samuelmedeirosjs/rescue-the-prisoner-Game.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd rescue-the-prisoner-Game
   ```
3. Abra o arquivo `index.html` (ou o arquivo principal do jogo) diretamente no seu navegador preferido, ou utilize a extensão **Live Server** no VS Code.
